PostLibrary.displayName Method

Parent Object: PostLibrary
Defined in namespace "adsk::cam" and the header file is <Cam/Post/PostLibrary.h>

Description

Get the localized display name for a given URL. The URL must point to a folder.

Syntax

  • Python
  • C++
"postLibrary_var" is a variable referencing a PostLibrary object.
returnValue = postLibrary_var.displayName(url)
"postLibrary_var" is a variable referencing a PostLibrary object.

#include <Cam/Post/PostLibrary.h>

returnValue = postLibrary_var->displayName(url);

Return Value

Type Description
string Returns localized display name for the folder. Returns empty string for invalid URL.

Parameters

Name Type Description
url URL The URL that defines the path to a folder.

Version

Introduced in version April 2023
