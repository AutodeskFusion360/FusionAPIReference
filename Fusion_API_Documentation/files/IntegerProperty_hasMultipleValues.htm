IntegerProperty.hasMultipleValues Property

Parent Object: IntegerProperty
Defined in namespace "adsk::core" and the header file is <Core/Application/IntegerProperty.h>

Description

Gets the boolean flag that indicates if this property has multiple values or not.

This is most commonly used for properties associated with materials and appearances.

Syntax

  • Python
  • C++
"integerProperty_var" is a variable referencing an IntegerProperty object.

# Get the value of the property.
propertyValue = integerProperty_var.hasMultipleValues
"integerProperty_var" Is a variable referencing an IntegerProperty Object.
#include <Core/Application/IntegerProperty.h>

// Get the value of the property.
boolean propertyValue = integerProperty_var->hasMultipleValues();

Property Value

This is a read only property whose value is a boolean.
