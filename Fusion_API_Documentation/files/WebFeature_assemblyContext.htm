WebFeature.assemblyContext Property

Parent Object: WebFeature
Defined in namespace "adsk::fusion" and the header file is <Fusion/Features/WebFeature.h>

Description

Returns the assembly occurrence (i.e. the occurrence) of this object in an assembly. This is only valid in the case where this is acting as a proxy in an assembly. Returns null in the case where the object is not in the context of an assembly but is already the native object.

Syntax

  • Python
  • C++
"webFeature_var" is a variable referencing a WebFeature object.

# Get the value of the property.
propertyValue = webFeature_var.assemblyContext
"webFeature_var" is a variable referencing a WebFeature object.
#include <Fusion/Features/WebFeature.h>

// Get the value of the property.
Ptr<Occurrence> propertyValue = webFeature_var->assemblyContext();

Property Value

This is a read only property whose value is an Occurrence.
