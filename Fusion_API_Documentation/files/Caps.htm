Caps Enumerator

Description

Shape applied to the endpoints of an open stroke (wire or arc).


Defined in namespace "adsk::electron" and the header file is <Electron\ElectronTypeDefs.h>

Values

Name Value Description
FlatCap 0 Flat (butt) cap; stroke ends exactly at the endpoint.
RoundCap 1 Round (semicircular) cap; stroke extends a half-width past the endpoint.
