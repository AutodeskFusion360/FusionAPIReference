ViaFlags Enumerator

Description

Behavioral flags for a via (e.g., solder mask opening).


Defined in namespace "adsk::electron" and the header file is <Electron\ElectronTypeDefs.h>

Values

Name Value Description
NoneViaFlag 0 Default via treatment; no solder mask or other flags set.
StopViaFlag 1 Solder mask (stop mask) opening; when set, the via gets a solder mask opening.

Version

Introduced in version May 2026
