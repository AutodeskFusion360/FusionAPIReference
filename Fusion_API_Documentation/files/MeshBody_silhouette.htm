Description

Calculates the silhouette of a mesh for a given orientation.

Syntax

  • Python
  • C++
"meshBody_var" is a variable referencing a MeshBody object.
returnValue = meshBody_var.silhouette(plane)
"meshBody_var" is a variable referencing a MeshBody object.

#include <Fusion/MeshBody/MeshBody.h>

returnValue = meshBody_var->silhouette(plane);

Return Value

Type Description
Polyline3D[] The results are returned as a list of polylines 3d objects. If the calculation fails, no polyline 3d objects are returned.

Parameters

Name Type Description
plane Plane Plane specifies the orienation for which the silhouette is calculated. The silhouette is calculated along the normal of the plane and projected on the plane after the calculation.
