InterLoopDimensionStrategyTypes Enumerator

Description

Defines dimension strategies for sketches with multiple loops. These strategies control how dimensions are created between different loops (profiles) within the same sketch.
Defined in namespace "adsk::fusion" and the header file is <Fusion\FusionTypeDefs.h>

Methods

Name Value Description
BaselineInterLoopDimensionStrategyType 2 All loops are dimensioned from a common datum or baseline, where each loop has dimensions that reference the same starting point.
ChainInterLoopDimensionStrategyType 1 Dimensions are chained from one loop to another, where each loop is dimensioned relative to the previous loop.
DefaultInterLoopDimensionStrategyType 0 Use the system's default inter-loop dimension strategy. This occurs when a new AutoConstrainInput is created and before a specific strategy has been set. When this value is used, the system will automatically select the most appropriate strategy based on the sketch geometry. This setting only applies to sketches with multiple loops.
