Description

Sets the annotation plane for Leader Line Note PMI.

Syntax

  • Python
  • C++
"pMILeaderLineNote_var" is a variable referencing a PMILeaderLineNote object.
# Uses no optional arguments.
returnValue = pMILeaderLineNote_var.setAnnotationPlane(planeType)

# Uses optional arguments.
returnValue = pMILeaderLineNote_var.setAnnotationPlane(planeType, face)
"pMILeaderLineNote_var" is a variable referencing a PMILeaderLineNote object.

#include <Fusion/PMI/PMILeaderLineNote.h>

// Uses no optional arguments.
returnValue = pMILeaderLineNote_var->setAnnotationPlane(planeType);

// Uses optional arguments.
returnValue = pMILeaderLineNote_var->setAnnotationPlane(planeType, face);

Return Value

Type Description
boolean True if the plane has been set successfully, false otherwise.

Parameters

Name Type Description
planeType LeaderLineNotePlaneTypes The type of annotation plane to create.

Setting Leader Line Note PMI to Unknown plane type is not supported.
face BRepFace An optional input face to define the plane.

Required if the planeType is NormalToCustomFaceLeaderLineNotePlaneType.

Required if the planeType is NormalToFaceLeaderLineNotePlaneType and the face must be an adjacent face to the geometry.

For other plane types, this parameter is ignored.

This is an optional argument whose default value is null.
