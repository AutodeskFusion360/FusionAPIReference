SmoothConstraint.nativeObject Property

Parent Object: SmoothConstraint
Defined in namespace "adsk::fusion" and the header file is <Fusion/Sketch/SmoothConstraint.h>

Description

The NativeObject is the object outside the context of an assembly and in the context of its parent component. Returns null in the case where this object is not in the context of an assembly but is already the native object.

Syntax

  • C++
"smoothConstraint_var" is a variable referencing a SmoothConstraint object.

# Get the value of the property.
propertyValue = smoothConstraint_var.nativeObject

This is a read only property whose value is a SmoothConstraint.
