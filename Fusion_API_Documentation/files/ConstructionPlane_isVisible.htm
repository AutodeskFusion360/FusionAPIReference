ConstructionPlane.isVisible Property

Parent Object: ConstructionPlane
Defined in namespace "adsk::fusion" and the header file is <Fusion/Construction/ConstructionPlane.h>

Description

Indicates if the construction plane is visible. This property is affected by the AssemblyContext of the construction plane.

Syntax

  • Python
  • C++
"constructionPlane_var" is a variable referencing a ConstructionPlane object.

# Get the value of the property.
propertyValue = constructionPlane_var.isVisible
"constructionPlane_var" is a variable referencing a ConstructionPlane object.
#include <Fusion/Construction/ConstructionPlane.h>

// Get the value of the property.
boolean propertyValue = constructionPlane_var->isVisible();

Property Value

This is a read only property whose value is a boolean.
