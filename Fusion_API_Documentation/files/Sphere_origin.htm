Sphere.origin Property

Parent Object: Sphere
Defined in namespace "adsk::core" and the header file is <Core/Geometry/Sphere.h>

Description

Gets and sets the origin point (center) of the sphere.

Syntax

  • Python
  • C++
"sphere_var" is a variable referencing a Sphere object.

# Get the value of the property.
propertyValue = sphere_var.origin

# Set the value of the property.
sphere_var.origin = propertyValue
"sphere_var" Is a variable referencing a Sphere Object.
#include <Core/Geometry/Sphere.h>

This is a read/write property whose value is a Point3D.
