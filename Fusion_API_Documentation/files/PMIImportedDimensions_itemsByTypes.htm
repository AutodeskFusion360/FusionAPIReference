Description

Gets all the PMIImportedDimension from the collection that match the specified PMI types.

Syntax

  • Python
  • C++
"pMIImportedDimensions_var" is a variable referencing a PMIImportedDimensions object.
returnValue = pMIImportedDimensions_var.itemsByTypes(types)
"pMIImportedDimensions_var" is a variable referencing a PMIImportedDimensions object.

#include <Fusion/PMI/PMIImportedDimensions.h>

returnValue = pMIImportedDimensions_var->itemsByTypes(types);

Return Value

Type Description
PMIImportedDimension[] Returns an array of PMI objects that match the specified types, or an empty array if no matching PMI were found.

Parameters

Name Type Description
types integer[] An array of PMITypes that specifies the types of PMI to return. If an empty array or null is passed, all the PMIImportedDimension from the collection will be returned regardless of type.
