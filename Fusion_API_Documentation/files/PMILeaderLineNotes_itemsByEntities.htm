Defined in namespace "adsk::fusion" and the header file is <Fusion/PMI/PMILeaderLineNotes.h>

Description

Gets all the PMILeaderLineNote from the collection that are associated with the specified geometric entities.

This is useful for finding PMILeaderLineNote that reference specific geometric features.

Syntax

  • C++
"pMILeaderLineNotes_var" is a variable referencing a PMILeaderLineNotes object.
returnValue = pMILeaderLineNotes_var.itemsByEntities(entities)
"pMILeaderLineNotes_var" is a variable referencing a PMILeaderLineNotes object.

#include <Fusion/PMI/PMILeaderLineNotes.h>

returnValue = pMILeaderLineNotes_var->itemsByEntities(entities);

Return Value

Type Description
PMILeaderLineNote[] Returns an array of PMILeaderLineNote objects that are associated with the specified entities and match the type filter (if provided) or an empty array if no matching PMI were found.

Parameters

Name Type Description
entities Base[] An array of core.Base objects that represent the geometric entities to search for associated PMI. These can be BRepFace, BRepEdge, BRepVertex, or BRepBody objects. The function will return the PMILeaderLineNote that references any of these entities in their geometric associations.
