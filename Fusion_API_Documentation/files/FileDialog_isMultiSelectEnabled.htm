FileDialog.isMultiSelectEnabled Property

Parent Object: FileDialog
Defined in namespace "adsk::core" and the header file is <Core/UserInterface/FileDialog.h>

Description

Gets or sets a value indicating whether the dialog box allows multiple files to be selected.

Syntax

  • Python
  • C++
"fileDialog_var" is a variable referencing a FileDialog object.

# Get the value of the property.
propertyValue = fileDialog_var.isMultiSelectEnabled

# Set the value of the property.
fileDialog_var.isMultiSelectEnabled = propertyValue
"fileDialog_var" is a variable referencing a FileDialog object.
#include <Core/UserInterface/FileDialog.h>

// Get the value of the property.
boolean propertyValue = fileDialog_var->isMultiSelectEnabled();

// Set the value of the property, where value_var is a boolean.

Property Value

This is a read/write property whose value is a boolean.
