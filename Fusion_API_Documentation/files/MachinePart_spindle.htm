MachinePart.spindle Property

Parent Object: MachinePart
Defined in namespace "adsk::cam" and the header file is <Cam/Machine/MachinePart.h>

Description

Get the spindle object for this part used to reference this part for other operations. Will return null if the part has no spindle assigned.

Syntax

  • Python
  • C++
"machinePart_var" is a variable referencing a MachinePart object.

# Get the value of the property.
propertyValue = machinePart_var.spindle
"machinePart_var" Is a variable referencing a MachinePart Object.
#include <Cam/Machine/MachinePart.h>

// Get the value of the property.
Ptr<MachineSpindle> propertyValue = machinePart_var->spindle();

Property Value

This is a read only property whose value is a MachineSpindle.

Version

Introduced in version April 2023
