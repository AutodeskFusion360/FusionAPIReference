EllipticalCone.majorRadius Property

Parent Object: EllipticalCone
Defined in namespace "adsk::core" and the header file is <Core/Geometry/EllipticalCone.h>

Description

Gets and sets the major radius of the ellipse that defines the cone.

Syntax

  • C++
