NCProgram.postProcess Method

Parent Object: NCProgram
Defined in namespace "adsk::cam" and the header file is <Cam/NCProgram/NCProgram.h>

Description

Creates machine-specific NC code for this NC program.

Syntax

  • Python
  • C++
"nCProgram_var" is a variable referencing a NCProgram object.
returnValue = nCProgram_var.postProcess(options)
"nCProgram_var" is a variable referencing a NCProgram object.

#include <Cam/NCProgram/NCProgram.h>

returnValue = nCProgram_var->postProcess(options);

Return Value

Type Description
boolean Returns true if the post process was successful.

Parameters

Name Type Description
options NCProgramPostProcessOptions NCProgramPostProcessOptions to speficy the behavior on internal warning. Can be null if the default values should be used. If needed it can be created by its static create() method.
