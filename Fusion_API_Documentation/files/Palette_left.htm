Palette.left Property

Parent Object: Palette
Defined in namespace "adsk::core" and the header file is <Core/UserInterface/Palette.h>

Description

Gets and sets the left side of the palette relative to screen space and in pixels. Because palettes can be positioned outside of the Fusion window, a value of zero indicates the left side of the screen and not the Fusion window.

Syntax

  • Python
  • C++
"palette_var" is a variable referencing a Palette object.

# Get the value of the property.
propertyValue = palette_var.left

# Set the value of the property.
palette_var.left = propertyValue
