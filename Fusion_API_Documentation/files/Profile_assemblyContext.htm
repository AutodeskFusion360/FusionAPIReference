Profile.assemblyContext Property

Parent Object: Profile
Defined in namespace "adsk::fusion" and the header file is <Fusion/Sketch/Profile.h>

Description

Returns the assembly occurrence (i.e. the occurrence) of this object in an assembly. This is only valid in the case where this is acting as a proxy in an assembly. Returns null in the case where the object is not in the context of an assembly. but is already the native object.

Syntax

  • Python
  • C++
"profile_var" is a variable referencing a Profile object.

# Get the value of the property.
propertyValue = profile_var.assemblyContext
"profile_var" is a variable referencing a Profile object.
#include <Fusion/Sketch/Profile.h>

// Get the value of the property.
Ptr<Occurrence> propertyValue = profile_var->assemblyContext();

Property Value

This is a read only property whose value is an Occurrence.
