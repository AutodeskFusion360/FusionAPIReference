TriadCommandInput.isHorizontalFlipVisible Property

Parent Object: TriadCommandInput
Defined in namespace "adsk::core" and the header file is <Core/UserInterface/TriadCommandInput.h>

Description

Gets and sets if the control that lets the user flip horizontally (around the Y-Z plane of the triad) is visible in both the graphical manipulator and the dialog.

Syntax

  • C++
