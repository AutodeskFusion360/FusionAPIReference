Defined in namespace "adsk::cam" and the header file is <Cam/CAM/CAM3MFExportStructure.h>

Description

Specifies the maximum number of parents listed in the name property for the mesh. If the number used is higher than the number of available parents, all parents are used. Given a body called Body1 whose assembly context's fullpath is "Manufacturing Models 1:1+ManufacturingModel 1:2+Unsaved (1)1:1+Component1:3", the following results are expected for the maximumMeshParentCount value given with "+" being used for the concatination: 

  • -1 - id="8" name="Manufacturing Models 1:1+ManufacturingModel 1:2+Unsaved (1)1:1+Component1:3+Body1"
  • 0 - id="8" name="Body1"
  • 1 - id="8" name="Component1:3+Body1"
  • 2 - id="8" name="Unsaved (1)1:1+Component1:3+Body1"
 By default, this value is set to 1.
