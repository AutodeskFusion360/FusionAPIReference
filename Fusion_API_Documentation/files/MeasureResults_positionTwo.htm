MeasureResults.positionTwo Property

Parent Object: MeasureResults
Defined in namespace "adsk::core" and the header file is <Core/Application/MeasureResults.h>

Description

For a distance measurement, this is the point on the second entity where the measurement was made to. For an angle measurement this is one of the three points defining the angle.

This is a read only property whose value is a Point3D.
