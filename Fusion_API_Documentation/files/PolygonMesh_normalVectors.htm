PolygonMesh.normalVectors Property

Parent Object: PolygonMesh
Defined in namespace "adsk::fusion" and the header file is <Fusion/MeshData/PolygonMesh.h>

Description

Returns the normal vectors as an array of Vector 3D objects. There is one normal vector for each index.

Syntax

  • Python
  • C++
"polygonMesh_var" is a variable referencing a PolygonMesh object.

# Get the value of the property.
propertyValue = polygonMesh_var.normalVectors
"polygonMesh_var" is a variable referencing a PolygonMesh object.
#include <Fusion/MeshData/PolygonMesh.h>

// Get the value of the property.
std::vector<Ptr<Vector3D>> propertyValue = polygonMesh_var->normalVectors();

Property Value

This is a read only property whose value is an array of type Vector3D.
