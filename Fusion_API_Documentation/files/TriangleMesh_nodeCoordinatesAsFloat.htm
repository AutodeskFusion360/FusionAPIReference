TriangleMesh.nodeCoordinatesAsFloat Property

Parent Object: TriangleMesh
Defined in namespace "adsk::fusion" and the header file is <Fusion/MeshData/TriangleMesh.h>

Description

Returns the node coordinates as an array of floats where they are the x, y, z components of each coordinate.

Syntax

  • Python
  • C++
"triangleMesh_var" is a variable referencing a TriangleMesh object.

# Get the value of the property.
propertyValue = triangleMesh_var.nodeCoordinatesAsFloat
"triangleMesh_var" is a variable referencing a TriangleMesh object.
#include <Fusion/MeshData/TriangleMesh.h>

// Get the value of the property.
std::vector<float> propertyValue = triangleMesh_var->nodeCoordinatesAsFloat();

Property Value

This is a read only property whose value is an array of type float.
