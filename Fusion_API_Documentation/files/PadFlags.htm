PadFlags Enumerator

Description

Behavioral flags for through-hole pads.


Defined in namespace "adsk::electron" and the header file is <Electron\ElectronTypeDefs.h>

Values

Name Value Description
FirstPadFlag 4 When set, uses the first (primary) pad shape from the shape list.
NonePadFlag 0 No flags set.
StopPadFlag 1 When set, generates solder stop mask opening for this pad.
ThermalsPadFlag 2 When set, generates thermal relief connections for supply layer pads.

Version

Introduced in version May 2026
