Defined in namespace "adsk::fusion" and the header file is <Fusion/PMI/PMIImportedNotes.h>

Description

Gets all the PMIImportedNote from the collection that are associated with the specified geometric entities.

This is useful for finding PMIImportedNote that reference specific geometric features.

Syntax

"pMIImportedNotes_var" is a variable referencing a PMIImportedNotes object.
returnValue = pMIImportedNotes_var.itemsByEntities(entities)
"pMIImportedNotes_var" is a variable referencing a PMIImportedNotes object.

#include <Fusion/PMI/PMIImportedNotes.h>

returnValue = pMIImportedNotes_var->itemsByEntities(entities);

Return Value

Type Description
PMIImportedNote[] Returns an array of PMIImportedNote objects that are associated with the specified entities and match the type filter (if provided) or an empty array if no matching PMI were found.

Parameters

Name Type Description
entities Base[] An array of core.Base objects that represent the geometric entities to search for associated PMI. These can be BRepFace, BRepEdge or BRepVertex objects. The function will return the PMIImportedNote that references any of these entities in their geometric associations.
