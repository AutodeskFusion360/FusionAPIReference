OperationBase.moveAfter Method

Parent Object: OperationBase
Defined in namespace "adsk::cam" and the header file is <Cam/Operations/OperationBase.h>

Description

Move operation in tree after the given operation. Throws an exception if a not allowed move is made for example moving a operation out of a setup.

Syntax

  • Python
  • C++
"operationBase_var" is a variable referencing an OperationBase object.
returnValue = operationBase_var.moveAfter(operation)
"operationBase_var" is a variable referencing an OperationBase object.

#include <Cam/Operations/OperationBase.h>

returnValue = operationBase_var->moveAfter(operation);

Return Value

Type Description
boolean Returns if move operation was successful.

Parameters

Name Type Description
operation OperationBase Operation to move targeted operation after.
