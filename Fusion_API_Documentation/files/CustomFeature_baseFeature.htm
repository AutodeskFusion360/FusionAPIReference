Defined in namespace "adsk::fusion" and the header file is <Fusion/Features/CustomFeature.h>

Description

If this feature is associated with a base feature, this property will return that base feature. If it's not associated with a base feature, this property will return null.

Syntax

  • C++
"customFeature_var" is a variable referencing a CustomFeature object.

# Get the value of the property.
propertyValue = customFeature_var.baseFeature
"customFeature_var" is a variable referencing a CustomFeature object.
#include <Fusion/Features/CustomFeature.h>

// Get the value of the property.
Ptr<BaseFeature> propertyValue = customFeature_var->baseFeature();

Property Value

This is a read only property whose value is a BaseFeature.
