PadShapes Enumerator

Description

Copper shape of a through-hole pad.


Defined in namespace "adsk::electron" and the header file is <Electron\ElectronTypeDefs.h>

Values

Name Value Description
AnnulusPadShape 5 Annulus (ring) pad shape; used on supply layers only.
LongPadShape 3 Long oblong pad shape for elongated holes.
OctagonPadShape 2 Octagonal pad shape.
OffsetPadShape 4 Offset elongated pad shape (asymmetric along one axis).
RoundPadShape 1 Round (circular) pad shape.
SquarePadShape 0 Square pad shape.
ThermalPadShape 6 Thermal relief pad shape; used on supply layers only.
