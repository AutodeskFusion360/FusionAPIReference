AdditiveFEAAnalysisType Enumerator

Description

The valid analysis types for an additive FEA simulation.
Defined in namespace "adsk::cam" and the header file is <Cam\CamTypeDefs.h>

Methods

Name Value Description
Mechanical 4 The `Mechanical` analysis type is for quasi-static mechanical analyses.
Thermal 2 The `Thermal` analysis type is for transient thermal conduction analyses.
ThermoMechanical 24 The `ThermoMechanical` analysis type combines both thermal and mechanical analyses in a single operation.
