SVGImportOptions.filename Property

Parent Object: SVGImportOptions
Defined in namespace "adsk::core" and the header file is <Core/Application/SVGImportOptions.h>

Description

Gets and sets the filename or URL of the file to be imported.

Syntax

  • C++
"sVGImportOptions_var" is a variable referencing a SVGImportOptions object.

# Get the value of the property.
propertyValue = sVGImportOptions_var.filename

# Set the value of the property.
sVGImportOptions_var.filename = propertyValue
