SketchArc.assemblyContext Property

Parent Object: SketchArc
Defined in namespace "adsk::fusion" and the header file is <Fusion/Sketch/SketchArc.h>

Description

Returns the assembly occurrence (i.e. the occurrence) of this object in an assembly. This is only valid in the case where this is acting as a proxy in an assembly. Returns null in the case where the object is not in the context of an assembly but is already the native object.

Syntax

  • Python
  • C++
"sketchArc_var" is a variable referencing a SketchArc object.

# Get the value of the property.
propertyValue = sketchArc_var.assemblyContext
"sketchArc_var" is a variable referencing a SketchArc object.
#include <Fusion/Sketch/SketchArc.h>

// Get the value of the property.
Ptr<Occurrence> propertyValue = sketchArc_var->assemblyContext();

Property Value

This is a read only property whose value is an Occurrence.
