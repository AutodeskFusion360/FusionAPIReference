SweepFeature.sideFaces Property

Parent Object: SweepFeature
Defined in namespace "adsk::fusion" and the header file is <Fusion/Features/SweepFeature.h>

Description

Property that returns an object that provides access to all of the faces created around the perimeter of the feature.

Syntax

  • Python
  • C++
"sweepFeature_var" is a variable referencing a SweepFeature object.

# Get the value of the property.
propertyValue = sweepFeature_var.sideFaces
"sweepFeature_var" is a variable referencing a SweepFeature object.
#include <Fusion/Features/SweepFeature.h>

// Get the value of the property.
Ptr<BRepFaces> propertyValue = sweepFeature_var->sideFaces();

Property Value

This is a read only property whose value is a BRepFaces.

Version
