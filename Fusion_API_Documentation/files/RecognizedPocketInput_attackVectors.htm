RecognizedPocketInput.attackVectors Property

Parent Object: RecognizedPocketInput
Defined in namespace "adsk::cam" and the header file is <Cam/PocketRecognition/RecognizedPocketInput.h>

Description

The attack vectors used to recognize pockets. If left empty, this array will be filled with normals of all planar faces on the given body. There vectors should be pointing down along the tool towards its tip and the pocket floors.
