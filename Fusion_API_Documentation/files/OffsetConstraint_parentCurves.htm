OffsetConstraint.parentCurves Property

Parent Object: OffsetConstraint
Defined in namespace "adsk::fusion" and the header file is <Fusion/Sketch/OffsetConstraint.h>

Description

Returns an array of sketch curves that are the set of parent curves. Nothing should be assumed about the order in how the curves are returned.

Syntax

  • Python
  • C++
"offsetConstraint_var" is a variable referencing an OffsetConstraint object.

# Get the value of the property.
propertyValue = offsetConstraint_var.parentCurves
"offsetConstraint_var" is a variable referencing an OffsetConstraint object.
#include <Fusion/Sketch/OffsetConstraint.h>

// Get the value of the property.
std::vector<Ptr<SketchCurve>> propertyValue = offsetConstraint_var->parentCurves();

Property Value

This is a read only property whose value is an array of type SketchCurve.

Version

Introduced in version May 2016
