CAMParameter.saveExpressionAsUserDefault Method

Parent Object: CAMParameter
Defined in namespace "adsk::cam" and the header file is <Cam/Operations/CAMParameter.h>

Description

Saves the current expression as user default value. Throws an exception if the parent is not an operation or does not support user default expressions.

Syntax

  • Python
  • C++
"cAMParameter_var" is a variable referencing a CAMParameter object.
returnValue = cAMParameter_var.saveExpressionAsUserDefault()

#include <Cam/Operations/CAMParameter.h>

Return Value
