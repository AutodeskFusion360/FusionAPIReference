Description

Creates a PMILeaderLineNoteInput object that is in turn used to create a Leader Line Note PMI.

Return Value

Type Description
PMILeaderLineNoteInput Returns a PMILeaderLineNoteInput object.

Parameters

Name Type Description
entity Base A core.Base object that represents the geometric entity to which the Note PMI will be associated.

This can be a BRepFace, BRepEdge, or BRepVertex object. For BRepEdge objects, only linear, circular and elliptical edges are supported. The note will be positioned relative to this entity and will maintain its association with the entity geometry. Native object will be used when setting the entity geometry.
