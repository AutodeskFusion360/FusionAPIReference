NCProgramInput.parameters Property

Parent Object: NCProgramInput
Defined in namespace "adsk::cam" and the header file is <Cam/NCProgram/NCProgramInput.h>

Description

Get all parameters for the current NC program. Parameters are initialized by user defaults. Configure operation parameters before creation for a better performance.

Syntax

  • Python
  • C++
"nCProgramInput_var" is a variable referencing a NCProgramInput object.

# Get the value of the property.
propertyValue = nCProgramInput_var.parameters
"nCProgramInput_var" is a variable referencing a NCProgramInput object.
#include <Cam/NCProgram/NCProgramInput.h>

// Get the value of the property.
Ptr<CAMParameters> propertyValue = nCProgramInput_var->parameters();

Property Value

This is a read only property whose value is a CAMParameters.
