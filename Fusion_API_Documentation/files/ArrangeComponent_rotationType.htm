ArrangeComponent.rotationType Property

Parent Object: ArrangeComponent
Defined in namespace "adsk::fusion" and the header file is <Fusion/Arrange/ArrangeComponent.h>

Description

Gets and sets the rotation type for this ArrangeComponent. This defaults to use the global rotation type defined for the arrangement.

For a 3D arrange, this property is ignored.

Syntax

  • Python
  • C++
"arrangeComponent_var" is a variable referencing an ArrangeComponent object.

# Get the value of the property.
propertyValue = arrangeComponent_var.rotationType

# Set the value of the property.
arrangeComponent_var.rotationType = propertyValue
"arrangeComponent_var" Is a variable referencing an ArrangeComponent Object.

Property Value

This is a read/write property whose value is an ArrangeRotationTypes.
