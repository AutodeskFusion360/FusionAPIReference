VectorError Enumerator

Description

Error values for various vector operations.


Defined in namespace "adsk::core" and the header file is <Core\CoreTypeDefs.h>

Values

Name Value Description
ZeroLengthVectorError 100 Zero length vector is not allowed. Vector operations such as IsParallel, IsPerpendicular, and angle calculations don't work with zero length vectors.
