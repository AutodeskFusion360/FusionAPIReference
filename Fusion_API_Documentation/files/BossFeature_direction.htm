BossFeature.direction Property

Parent Object: BossFeature
Defined in namespace "adsk::fusion" and the header file is <Fusion/Plastic/BossFeature.h>

Description

Returns the direction of the boss feature with respect to selected position point. For selected sketch point this direction represents a Z-axis of the sketch.

Syntax

  • Python
  • C++
"bossFeature_var" is a variable referencing a BossFeature object.

# Get the value of the property.
propertyValue = bossFeature_var.direction
"bossFeature_var" Is a variable referencing a BossFeature Object.
#include <Fusion/Plastic/BossFeature.h>

// Get the value of the property.
Ptr<Vector3D> propertyValue = bossFeature_var->direction();

Property Value

This is a read only property whose value is a Vector3D.
