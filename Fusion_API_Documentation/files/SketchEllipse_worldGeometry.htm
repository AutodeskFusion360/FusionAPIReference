SketchEllipse.worldGeometry Property

Parent Object: SketchEllipse
Defined in namespace "adsk::fusion" and the header file is <Fusion/Sketch/SketchEllipse.h>

Description

Returns an Ellipse3D object which provides geometric information in world space. The returned geometry takes into account the assembly context and the position of the sketch in its parent component, which means the geometry will be returned in the root component space.

Syntax

  • Python
  • C++
"sketchEllipse_var" is a variable referencing a SketchEllipse object.

# Get the value of the property.
propertyValue = sketchEllipse_var.worldGeometry
"sketchEllipse_var" Is a variable referencing a SketchEllipse Object.
#include <Fusion/Sketch/SketchEllipse.h>

// Get the value of the property.
Ptr<Ellipse3D> propertyValue = sketchEllipse_var->worldGeometry();

Property Value

This is a read only property whose value is an Ellipse3D.
