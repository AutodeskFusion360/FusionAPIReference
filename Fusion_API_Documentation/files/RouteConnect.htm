RouteConnect Enumerator

Description

How a contact reference connects when the element has multiple gates.


Defined in namespace "adsk::electron" and the header file is <Electron\ElectronTypeDefs.h>

Values

Name Value Description
AllRouteConnect 0 Connect to all gates (default); any gate can fulfill the connection.
AnyRouteConnect 1 Connect to a specific gate only; routetag specifies which gate and pin.

Version

Introduced in version May 2026
