SymmetricDimensionStrategyTypes Enumerator

Description

Defines dimension strategies for symmetric geometry. These strategies control how dimensions are created when symmetric features are detected in the sketch.


Defined in namespace "adsk::fusion" and the header file is <Fusion\FusionTypeDefs.h>

Values

Name Value Description
CenterToEndSymmetricDimensionStrategyType 3 Dimensions are created from the center line or center point of the symmetric feature to one edge.
CenterToEndWithSymmetryConstraintSymmetricDimensionStrategyType 4 Dimensions are created from center to end, and explicit symmetry constraints are added to ensure the feature remains symmetric when dimensions are changed.
DefaultSymmetricDimensionStrategyType 0 Use the system's default symmetric dimension strategy. This occurs when a new AutoConstrainInput is created and before a specific strategy has been set. When this value is used, the system will automatically select the most appropriate strategy based on the sketch geometry. This setting only applies when symmetric dimensioning strategies are used.
EndToCenterSymmetricDimensionStrategyType 2 Dimensions are created from one edge of the symmetric feature to its center line or center point.
EndToEndSymmetricDimensionStrategyType 1 Dimensions span from one end of the symmetric feature to the other end, creating a single dimension across the entire symmetric feature.
