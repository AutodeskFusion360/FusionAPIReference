ConfigurationCustomThemeTable.moveColumns Method

Parent Object: ConfigurationCustomThemeTable
Defined in namespace "adsk::fusion" and the header file is <Fusion/Configurations/ConfigurationCustomThemeTable.h>

Description

Moves the specified columns from one table to another.

Syntax

  • Python
  • C++
"configurationCustomThemeTable_var" is a variable referencing a ConfigurationCustomThemeTable object.
returnValue = configurationCustomThemeTable_var.moveColumns(columns, targetTable)
"configurationCustomThemeTable_var" is a variable referencing a ConfigurationCustomThemeTable object.

#include <Fusion/Configurations/ConfigurationCustomThemeTable.h>

returnValue = configurationCustomThemeTable_var->moveColumns(columns, targetTable);

Return Value

Type Description
ConfigurationColumn[] Returns an array of the columns created due to the move.

Parameters

Name Type Description
columns ConfigurationColumn[] An array of the columns within this table that you want to move.
targetTable ConfigurationTable The table you want to move the columns to. The target must be either a top table or a custom theme table.

Version
