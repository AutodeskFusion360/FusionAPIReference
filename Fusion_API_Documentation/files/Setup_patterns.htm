Setup.patterns Property

Parent Object: Setup
Defined in namespace "adsk::cam" and the header file is <Cam/CAM/Setup.h>

Description

Returns the Patterns collection that provides access to existing patterns in this setup.

Syntax

  • C++
"setup_var" is a variable referencing a Setup object.

# Get the value of the property.
propertyValue = setup_var.patterns
"setup_var" is a variable referencing a Setup object.
#include <Cam/CAM/Setup.h>

// Get the value of the property.

Property Value

This is a read only property whose value is a CAMPatterns.
