FlatPatternComponent.sketches Property

Parent Object: FlatPatternComponent
Defined in namespace "adsk::fusion" and the header file is <Fusion/SheetMetal/FlatPatternComponent.h>

Description

Returns the sketches collection associated with this component. This provides access to the existing sketches and supports the creation of new sketches.
