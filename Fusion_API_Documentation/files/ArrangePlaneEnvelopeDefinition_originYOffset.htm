ArrangePlaneEnvelopeDefinition.originYOffset Property

Parent Object: ArrangePlaneEnvelopeDefinition
Defined in namespace "adsk::fusion" and the header file is <Fusion/Arrange/ArrangePlaneEnvelopeDefinition.h>

Description

Returns the parameter that controls the Y offset of the frame from the origin of the construction plane. You can modify the value by using the properties on the returned ModelParameter object.
