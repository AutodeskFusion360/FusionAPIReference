Component.propertyGroups Property

Parent Object: Component
Defined in namespace "adsk::fusion" and the header file is <Fusion/Components/Component.h>

Description

Returns the PropertyGroups object associated with this component.

Syntax

  • Python
  • C++
"component_var" is a variable referencing a Component object.

# Get the value of the property.
propertyValue = component_var.propertyGroups
"component_var" Is a variable referencing a Component Object.
#include <Fusion/Components/Component.h>

// Get the value of the property.
Ptr<PropertyGroups> propertyValue = component_var->propertyGroups();

Property Value

This is a read only property whose value is a PropertyGroups.
