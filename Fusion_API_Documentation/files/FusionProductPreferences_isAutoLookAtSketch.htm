FusionProductPreferences.isAutoLookAtSketch Property

Parent Object: FusionProductPreferences
Defined in namespace "adsk::fusion" and the header file is <Fusion/Fusion/FusionProductPreferences.h>

Description

This function is retired. See more information in the 'Remarks' section below.

Gets and sets if the view is re-oriented to view the newly created sketch. This property has been replaced by the isAutoLookAtSketch2 property, which provides the full capabilities.

Remarks

This property is deprecated. Use isAutoLookAtSketch2 instead.
