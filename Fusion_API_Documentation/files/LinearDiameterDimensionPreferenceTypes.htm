LinearDiameterDimensionPreferenceTypes Enumerator

Description

Defines preferences for linear diameter dimensions in sketches. Linear diameter dimensions measure the diameter of circular or rotational features using a centerline and parallel edges or points, rather than directly dimensioning a circle or arc. The dimension displays with the Ø symbol and measures the full diameter across the feature. This dimensioning style is commonly used for turned components and rotational features in machining drawings, where you dimension the diameter using a centerline as the reference rather than the circular geometry itself.
Defined in namespace "adsk::fusion" and the header file is <Fusion\FusionTypeDefs.h>

Methods

Name Value Description
AvoidLinearDiameterDimensionPreferenceType 2 Avoid creating linear diameter dimensions. The system will use radial dimensions or standard diameter dimensions that directly reference circular geometry instead of using centerlines.
DefaultLinearDiameterDimensionPreferenceType 0 Use the system's default behavior for linear diameter dimensions. This occurs when a new AutoConstrainInput is created and before a specific preference has been set. When this value is used, the system will decide whether to use linear diameter dimensions based on the sketch geometry and context.
PreferLinearDiameterDimensionPreferenceType 1 Prefer to create linear diameter dimensions (using centerlines) when dimensioning circular or rotational features. The system will favor linear diameter dimensions over radial dimensions or standard diameter dimensions that directly reference circles or arcs. This is useful for sketches representing turned components and machining drawings where centerline-based diametrical dimensioning is standard practice.
